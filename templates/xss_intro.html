What is Reflected XSS?

Reflected Cross-Site Scripting happens when a page takes user input and writes it directly into the HTML without escaping. If an attacker tricks a victim into clicking a link with a malicious payload, the victim's browser runs that script — potentially stealing cookies, redirecting them, or defacing the page.

Your task

  1. Open the Challenge page — it has a vulnerable greeting form.
  2. Submit a payload that injects HTML / JavaScript.
  3. The lesson completes the moment your input contains an XSS pattern.

How this app prevents XSS

  • All Jinja2 template output is HTML-escaped by default. {{'{{ value }}'}} turns <script> into harmless text.
  • Input validation in security.py blocks usernames that contain HTML metacharacters.
  • Session cookies are HttpOnly — even a successful XSS can't read them.
